# Project Profile

Initialized evidence-aware Phase A Ikariam browser simulator. Python 3.11+, pure `ikariam_battle.simulate()`, no-framework ASGI/Vercel, vanilla UI, packaged profiles under `ikariam_battle/data/`.

Inputs are profile bundle, explicit battlefield ID, strict/experimental policy, side-wide Forge, unit-specific Workshop levels, units/waves. Outputs include positioned slots, reserve, ammo-pool shots, damage/casualties, all-survivor totals, main-line/fallback continuation state, termination events, and assumptions actually applied. Function B is excluded.

Facts: reviewer-web-verified current data through 17.5.0 is distinct from empirical PDF mechanics. All five land geometries plus `naval-max` are operational through explicit baseline IDs; smaller naval geometries remain unsupported. Configured settlement/garrison state may override the effective land field to `land-max`, while later cross-geometry transitions remain guarded. Player defender Town Hall 1..66, Barbarian Village 1..50, and Town Wall 0..48 are explicit scenario/UI inputs. Player garrison-limit uses `250 + 50 × (Town Hall + Wall)`; configured Barbarian defenders use the 2024 Gameforge-forum community rule `(Village + Wall + 5) × 50`. Open-field start is executable using actual unit counts with v17.4 Doctor/Cook exclusion; threshold crossings are detected but cross-geometry transition execution is guarded. Published wall stats/segments are represented. Wall-first Land Artillery priority and strict `effective ATK > effective DEF` penetration eligibility are known/represented. Strict keeps active wall combat behind `UNKNOWN-TOWN-WALL-COMBAT`; Experimental executes the explicitly named/calibrated subset for section HP/breach, breached-position First exposure, flank lock, exact divisible redistribution, and same-geometry fresh-wall re-entry. Exact wall section order, wall offensive Accuracy/individual-target behavior, non-divisible redistribution, and cross-geometry transition remain guarded. Duplicate same unit/wave/upgrades normalize; contradictory same-unit upgrades reject; input ordering is not a rule; ammo is pooled shots; support healing and morale are distinct. The official Accuracy algorithm remains unresolved: Strict blocks on `UNKNOWN-ACCURACY`, while Experimental uses the named deterministic `EXP-ACCURACY-CONCENTRATION-001` within-slot concentration hypothesis and does not model Accuracy as Bernoulli misses. Unknowns never silently produce exact strict outcomes.
