# Architecture

Scenario models unit-specific Workshop upgrades and side Forge; registry models domain, role/support effect, semantic class, native line, size, and per-weapon accuracy/ammo. Packaged mechanics, units, Workshop, Forge, support, formation, targeting, battle-end, and calibration data load through `importlib.resources`. Battlefield geometry owns slot space; the pure planner derives capacity, applies Heavy-before-Light and front-before-flank precedence, and assigns runtime `Slot.line` without mutating native metadata. Targeting and battle-end holding consume runtime lines; legacy `battlefield_class` remains compatibility metadata. Mixed runtime lines are representable but mixed-unit Am and non-native fallback combat remain guarded. Multi-line `Wave` execution remains guarded as `UNKNOWN-MULTILINE-WAVE-COMBAT-SEMANTICS`. Round-start formation rebuild precedes RR. Engine uses entry-batch damage/ammo pools, named experimental policies, and simultaneous phase-start plans. UI/API render authoritative metadata.
