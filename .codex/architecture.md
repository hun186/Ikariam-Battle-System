# Architecture

Scenario models unit-specific Workshop upgrades and side Forge; registry models domain, role/support effect, size, and per-weapon accuracy/ammo. Packaged mechanics, units, Workshop, Forge, support, targeting, and battle-end profiles load through `importlib.resources`. Battlefield geometry owns slot space; deployment derives `slot_space // size`. Engine preflights unknowns, uses per-wave damage/ammo pools, legacy targeting only as a named experimental policy, and phase-start simultaneous plans. Outcomes distinguish actual main-line holders from unresolved fallback candidates and non-sustaining survivors; fallback boundaries are evaluated initially and after every completed round. Applied assumptions are deduplicated. UI/API render authoritative metadata. Calibration fixtures compare observed reports without hard-coded winners.
