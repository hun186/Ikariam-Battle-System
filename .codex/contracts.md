# Interface Contracts

`simulate` input contains profiles (`mechanics`, `unit_stats`, `workshop`, `forge`, `support`, `targeting`, `battle_end`, `formation`), policy, `land-mini`, max rounds, and armies with side `forge_level` plus `units[{unit_id,quantity,wave_id,attack_upgrade,armor_upgrade}]`. Upgrades are non-negative integers; same unit on one side must use consistent upgrades. Strict unsupported behavior is inconclusive; experimental assumptions have stable, unique IDs and only report applied policies. Snapshots keep `total` and add `main_line_holding_total`, `fallback_candidate_total`, and `continuation_state`; termination is a separate event and never fabricates casualties. `fallback_required` is an inconclusive boundary in both policies.

`GET /api/simulate` returns the canonical `Profiles()` bundle (including `formation`), verified-through metadata, supported/reserved battlefields, complete units with domain/role/support effect plus semantic class/native line, Forge levels and support capacity. `POST` returns result or 400 validation error. Packaged data is the registry authority; UI has no duplicate list.

Wave identity is entry-batch identity. Ammo live pool and frozen normal entry capacity belong to the wave and are shared by all of its slots; the percentage is Phase-A-derived rather than a verified game tooltip formula. Snapshot `waves` and additive slot fields expose entry batch, display/taxonomy, upgrades, engine-derived slot-level surviving-unit HP percentage, and wave-level munition percentage. `Wave.slots` can structurally represent more than one runtime line, but `UNKNOWN-MULTILINE-WAVE-COMBAT-SEMANTICS` prevents that uncalibrated state from entering rebuild, RR, targeting, or fire. A reserve-only combat wave whose native line is already occupied is guarded by `UNKNOWN-CROSS-WAVE-FORMATION-REBUILD`; ordinary reserve refill within one wave remains supported. Heavy/Light runtime-first formation is representable. `UNKNOWN-FALLBACK-LIGHT-INFANTRY-COMBAT` and `UNKNOWN-MIXED-UNIT-AM-ROWS` prevent representation from silently enabling uncalibrated combat.
